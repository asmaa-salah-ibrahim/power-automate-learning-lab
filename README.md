# Power Automate Learning Lab

Hands-on learning and practice repository for Microsoft Power Automate.

This repository documents my practical learning journey with Power Automate,
created to strengthen my automation skills and deepen my understanding of
Power Platform concepts after earning the PL-200 certification.

---

## 🎯 Learning Goals

- Build a strong practical understanding of Power Automate
- Create and manage cloud flows
- Understand triggers, actions, and dynamic content
- Work with expressions, conditions, and control logic
- Build approval-based workflows
- Work with connectors and HTTP requests
- Perform data operations
- Integrate Power Automate with Power Apps and Dataverse
- Explore AI-powered automation
- Apply Power Automate to real-world business processes
- Strengthen my Power Platform and CRM development skills
